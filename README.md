# VK Weather Bot

Production-ready погодный бот для ВКонтакте на базе **VKBottle 4.x** и **OpenWeatherMap API**.

Бот предоставляет текущую погоду, прогноз на 5 дней, погоду по геолокации и расширенный режим с данными о качестве воздуха (AQI, PM2.5, PM10, O₃).

## Возможности

| Функция | Описание |
|---|---|
| 🌤 Погода сейчас | Текущая температура, ощущается как, влажность, давление, ветер, видимость |
| 📅 Прогноз 5 дней | Почасовой прогноз с агрегацией по дням (мин/макс температура, влажность, ветер) |
| 📍 Геолокация | Погода по VK-геолокации или ручному вводу координат (`55.7558, 37.6173`) |
| 🌫 Расширенный режим | Погода + качество воздуха: AQI, PM2.5, PM10, O₃ с анализом и рекомендациями |
| ℹ️ Помощь | Справка по всем функциям бота |

## Технологии

- **Python 3.11+**
- **VKBottle 4.10** — асинхронный фреймворк для VK API (Long Poll)
- **OpenWeatherMap API** — погодные данные
- **python-dotenv** — управление переменными окружения
- **requests** — HTTP-запросы к OpenWeatherMap
- **loguru** — логирование VKBottle

## Установка

### 1. Клонирование и зависимости

```bash
cd weather_vk_bot
python -m venv .venv
```

Активация виртуального окружения:

**Windows (PowerShell):**
```powershell
.\.venv\Scripts\Activate.ps1
```

**Linux / macOS:**
```bash
source .venv/bin/activate
```

Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 2. Получение токенов

#### VK Bot Token (Long Poll API)

1. Откройте управление сообществом ВКонтакте
2. Раздел **«API и вебхуки»** → **«Long Poll API»**
3. Нажмите **«Подключить»** и скопируйте токен

#### OpenWeatherMap API Key

1. Зарегистрируйтесь на [openweathermap.org](https://openweathermap.org/api)
2. Перейдите в раздел **API Keys**
3. Скопируйте ваш ключ

### 3. Настройка .env

Создайте файл `.env` в папке `weather_vk_bot/`:

```env
VK_BOT_TOKEN=ваш_токен_сообщества
OPENWEATHER_API_KEY=ваш_ключ_openweather
WEATHER_API_BASE=https://api.openweathermap.org/data/2.5
```

> ⚠️ **Важно:** Файл `.env` должен быть сохранён в кодировке **UTF-8 без BOM**. Если вы создаёте его в PowerShell, используйте Python для записи, чтобы избежать BOM-символов.

### 4. Запуск

```bash
python main.py
```

После запуска в терминале появится:
```
INFO     | Loop will be run forever
INFO     | Starting BotPolling for <API ...>
INFO     | Starting listening to BotPolling longpoll
```

Напишите боту **«Начать»** в личные сообщения сообщества.

## Архитектура

### FSM-состояния

Бот использует `BuiltinStateDispenser` для управления сценариями:

| Состояние | Описание |
|---|---|
| `MAIN` | Главное меню — ожидание нажатия кнопки |
| `WAITING_CITY` | Ожидание ввода города для текущей погоды |
| `WAITING_FORECAST_CITY` | Ожидание ввода города для прогноза |
| `WAITING_GEO` | Ожидание геолокации или координат |
| `WAITING_EXTENDED` | Ожидание ввода города для расширенного режима |

### Обработка сообщений

Хендлеры разделены на два лейблера, загружаемых в порядке приоритета:

1. **`menu_labeler`** — обрабатывает нажатия кнопок клавиатуры (по `payload`)
2. **`text_labeler`** — обрабатывает текстовый ввод (город, координаты) на основе текущего FSM-состояния

### Клавиатуры

Все кнопки используют **payload** (`{"cmd": "..."}`) для надёжной обработки, независимо от эмодзи в тексте кнопки.

| Кнопка | Payload |
|---|---|
| 🌤 Погода сейчас | `{"cmd": "weather_now"}` |
| 📅 Прогноз 5 дней | `{"cmd": "forecast"}` |
| 📍 Геолокация | `{"cmd": "geo"}` |
| 🌫 Расширенный режим | `{"cmd": "extended"}` |
| ℹ️ Помощь | `{"cmd": "help"}` |
| 🏠 Главное меню | `{"cmd": "main"}` |
| ❌ Отмена | `{"cmd": "cancel"}` |

### Обработка ошибок

`WeatherService` обрабатывает все типы ошибок API:

- **404** — город не найден
- **401** — ошибка авторизации API
- **429** — превышение лимита запросов
- **Timeout** — превышение времени ожидания
- **ConnectionError** — нет соединения с сервером
